# AGENTS.md

## Project Overview

zig-parquet is a native Parquet library written in Zig 0.16.0 and 0.17.0 (one source tree). It provides read/write support for Parquet files, a C ABI, and a CLI tool (`pqi`). Read `README.md` for the full feature list and API examples.

## Project Structure

- `zig-parquet/` - Core Parquet library
- `cli/` - `pqi` CLI tool
- `zig-{zstd,brotli,lz4,gzip,snappy}/` - Pure Zig compression codec packages
- `test-files-arrow/` - Test files generated by Python (uses uv)
- `test-files-wild/` - Real-world Parquet files for compatibility testing

### Key Files

- `zig-parquet/src/lib.zig` - Library exports (package root)
- `zig-parquet/src/core/dynamic_reader.zig` - DynamicReader (schema-agnostic row reading)
- `zig-parquet/src/core/column_decoder.zig` - Column value decoding (encodings, levels, types)
- `zig-parquet/src/core/writer.zig` - High-level typed Parquet writer
- `zig-parquet/src/core/dynamic_writer.zig` - DynamicWriter (runtime-schema row writing)
- `zig-parquet/src/core/format.zig` - Parquet format types (re-exports from format/)
- `zig-parquet/src/core/safe.zig` - Safe casting/slicing helpers for untrusted data
- `zig-parquet/src/core/arrow_batch.zig` - Arrow C Data Interface bridge
- `zig-parquet/src/core/schema.zig` - Recursive schema for nested types + logical types
- `cli/src/main.zig` - pqi CLI entry point

### Documentation

- `ROADMAP.md` - Development phases and progress
- `zig-parquet/HARDENING.md` - Hardening guidelines
- `test-files-wild/README.md` - Test file validation status

## Build & Test

**Always run from the repo root via `make`. Never `cd` into `zig-parquet/` or `cli/`** — the tool session preserves cwd across commands, so a stray `cd` strands later commands in the wrong directory. The Makefile's recipes handle the `cd` in a subshell so the outer cwd is unchanged.

`test`, `lib`, and `cli` accept `CODECS=<spec>` and `OPT=<ReleaseSmall|ReleaseFast|ReleaseSafe|Debug>` as make variables — don't add new fixed targets for each combination.

```bash
make help                              # List all targets with examples
make build                             # Build library + CLI (defaults)
make test                              # Library tests, all codecs (Zig preferred)
make test CODECS=zig-only              # Pure Zig codecs only (no C deps)
make test CODECS=c-only                # C/C++ codecs only
make test CODECS=none                  # Non-compression tests only
make test CODECS=c-zstd,zstd           # Cross-implementation (both zstd codecs)
make lib CODECS=c-brotli OPT=ReleaseSmall  # Size-measured release build
make example NAME=basic                # Build an example (NAME is required)
make example NAME=wasm_demo OPT=ReleaseSmall
make wasm                              # Verify WASM targets compile and link
make validate-wild                     # Validate pqi against wild files (failures)
make validate-wild-all                 # Validate pqi against wild files (all)
make bench ZIG=<path> ROWS=100000      # Benchmark harness (ReleaseFast, zig-only codecs); ROWS defaults to 1000000
make bench-rust ROWS=100000            # Same scenarios with the Rust parquet crate (bench/rust)
make bench-js-browsers ROWS=100000     # zig-parquet WASM vs hyparquet / parquet-wasm in Chrome + Firefox (bench/js)
make bench-js-workerd ROWS=100000      # The same in workerd; results write-up in bench/COMPARE.md
make fmt ZIG=<0.16 zig>                # zig fmt across sources (0.16 only)
make clean                             # Remove .zig-cache and zig-out everywhere
```

`CODECS` values: `all` (default), `none`, `zig-only`, `c-only`, or comma-separated list from `zstd,snappy,gzip,lz4,brotli` (Zig) and `c-zstd,c-snappy,c-gzip,c-lz4,c-brotli` (C/C++).

## Dual-version rules

Every line under `zig-parquet/` and `cli/` must compile on both Zig 0.16.0 and 0.17.0.

| never write | write instead |
|---|---|
| `[_]T{v} ** n`, `.{v} ** n` | `@as([n]T, @splat(v))`, or `var a: [n]T = @splat(v);` |
| `"abc" ** n` | `comptime repeat.bytes("abc", n)` (`src/repeat.zig`) |
| `@cImport` / `@cInclude` | hand-written `const c = struct { extern fn ...; }` |
| `allocator.dupeZ(u8, x)` | `allocator.dupeSentinel(u8, x, 0)` |
| `std.hash.crc.Crc32`, `crc.@"CRC-32/ISO-HDLC"` | `std.hash.Crc32` |
| `b.args` / `run.addPassthruArgs()` in build.zig | `passArgs(b, run)` helper |
| `@backingInt`, `@fromBackingInt` | `@intFromEnum`, `@enumFromInt` |
| `allocator.print(...)`, `allocator.printSentinel(...)` | `std.fmt.allocPrint(...)`, `std.fmt.allocPrintSentinel(...)` |
| `std.heap.SafeAllocator`, `std.heap.GeneralPurposeAllocator` | `std.heap.DebugAllocator(.{})` |
| `std.meta.fields`, `std.meta.Int`, `std.meta.Tag` (new uses) | explicit types / `switch (T)` |

- **`zig fmt` only with 0.16** (`make fmt ZIG=<Z16>`). 0.17's fmt rewrites builtins to 0.17-only
  spellings. Do not let an editor format with 0.17.
- Do not follow the `zig-0-17` skill or main's 0.17-only code for spellings. Use the table above.
- Version gates (`builtin.zig_version`) are **not** allowed in `src/`. If you hit a 0.16/0.17
  difference not in the table, **stop and ask**.

Pick the toolchain per invocation with `ZIG=<path>` (default: `zig` on PATH), for example
`make test ZIG=C:/tools/zig-0.16.0/zig.exe` or `make test ZIG=C:/tools/zig-0.17.0/zig.exe`.
Non-0.16 toolchains use the gitignored `.zig17/cache` directory so their build caches stay separate.

## Zig 0.16.0 and 0.17.0 — Key API Patterns

Always search the codebase for existing patterns before writing new code.

### std.Io Interface

Zig 0.17 uses a unified `std.Io` interface for all I/O. File operations require an `io: std.Io` parameter.

- **In `main`**: Accept `std.process.Init` — provides `init.io`, `init.gpa`
- **In tests**: Use `std.testing.io`
- **In library code**: Thread `io` through from caller

### File I/O

```zig
// Open/create files
const file = try std.Io.Dir.cwd().openFile(io, "path.parquet", .{});
defer file.close(io);

// Positional reads (replaces seekTo + read)
const n = try file.readPositionalAll(io, buffer, offset);

// Streaming writer
var buf: [8192]u8 = undefined;
var file_writer = file.writerStreaming(io, &buf);
const writer: *std.Io.Writer = &file_writer.interface;
try writer.writeAll(data);
try file_writer.interface.flush();
```

### ArrayList / ArrayListUnmanaged

```zig
var list: std.ArrayList(T) = .empty;     // NOT .init(allocator), NOT .{}
try list.append(allocator, item);         // allocator passed to ALL methods
const slice = try list.toOwnedSlice(allocator);
list.deinit(allocator);
```

### Memory-backed Writers

```zig
var out: std.Io.Writer.Allocating = .init(allocator);
defer out.deinit();
try out.writer.writeAll(data);
const owned = try out.toOwnedSlice();
```

### stdout / stderr

```zig
var buf: [256]u8 = undefined;
var stdout_writer = std.Io.File.stdout().writerStreaming(io, &buf);
const stdout = &stdout_writer.interface;
try stdout.writeAll("message\n");
try stdout_writer.interface.flush();
```

### Enum Conversion

```zig
// std.meta.intToEnum was removed — use std.enums.fromInt (returns ?T)
const codec = std.enums.fromInt(CompressionCodec, v) orelse return error.InvalidCodec;

// Use @intFromEnum / @enumFromInt (works on 0.16 and 0.17); never @backingInt / @fromBackingInt
const raw: u8 = @intFromEnum(status);
const restored: Status = @enumFromInt(raw);
```

### Target and formatting

```zig
const arch = @import("builtin").target.cpu.arch;

// std.fmt.allocPrint moved onto the allocator
const name = try std.fmt.allocPrint(allocator, "name_{d}", .{i});
```

### Custom Format Functions

```zig
pub fn format(self: @This(), writer: *std.Io.Writer) std.Io.Writer.Error!void {
    try writer.print("{}", .{self.value});
}
```

### JSON Serialization

```zig
// Serialize
var out: std.Io.Writer.Allocating = .init(allocator);
errdefer out.deinit();
try std.json.Stringify.value(data, .{}, &out.writer);
return out.toOwnedSlice();

// Parse
var parsed = try std.json.parseFromSlice(MyData, allocator, json, .{});
defer parsed.deinit();
```

### ArenaAllocator

```zig
_ = arena.reset(.free_all);           // NOT arena.reset()
_ = arena.reset(.retain_capacity);
```

### Build Options (Conditional Compilation)

Compression codecs are controlled via `-Dcodecs=` (default: `all`).

Presets: `all` (C + Zig, Zig used by default), `c-only` (C/C++ only), `zig-only` (no C deps), `none`, or comma-separated list: `c-zstd,zstd,c-snappy,snappy,c-gzip,gzip,c-lz4,lz4,c-brotli,brotli`.

```zig
// Zig implementations (default); C implementations opt-in via c-only or c-<codec>
pub const zig_zstd = if (build_options.enable_zig_zstd) @import("zstd.zig") else {};
pub const zig_snappy = if (build_options.enable_zig_snappy) @import("snappy.zig") else {};
pub const zstd = if (build_options.enable_zstd) @import("c_zstd.zig") else {};
pub const snappy = if (build_options.enable_snappy) @import("c_snappy.zig") else {};
```

In tests, guard codec-specific tests with `supports_*` flags:

```zig
test "my zstd test" {
    if (!build_options.supports_zstd) return;
    // ...
}
```

### WASM Targets

- `export fn` does NOT use `callconv(.C)` on WASM — it won't compile.
- `wasm32-freestanding` won't work with `std.posix`, `std.Thread`, or `std.debug.print`. Use `wasm32-wasi`.

### Before Writing Code

1. Search the codebase for similar patterns first.
2. Compile incrementally — test after every 20-30 lines, not 200.
3. Read compiler errors carefully — Zig's errors are precise.
4. Never call deprecated methods — check for newer alternatives.

## Hardening Requirements

Both reader and writer handle **untrusted data**. Code must return errors instead of panicking on malformed input. See `zig-parquet/HARDENING.md` for full details.

### Never Use `@intCast` on External Data

Use `safe.zig` for all external data casting:

```zig
const safe = @import("safe.zig");

// BAD — panics if value doesn't fit
const size: usize = @intCast(header.page_size);

// GOOD — returns error if value is negative or out of range
const size = try safe.cast(header.page_size);
const count = try safe.castTo(u32, header.num_values);
```

### `catch unreachable` Requirements

When a value is mathematically guaranteed to fit, use `catch unreachable` but MUST include an inline comment explaining why:

```zig
const bit_idx: u3 = safe.castTo(u3, i % 8) catch unreachable; // i % 8 is strictly 0-7

if (value.len > std.math.maxInt(i32)) return error.ValueTooLarge;
const len = safe.castTo(i32, value.len) catch unreachable; // Checked against maxInt(i32) above
```

### Always Bounds-Check Before Slicing or Indexing

```zig
// BAD — panics if out of bounds
const value = data[offset..][0..length];

// GOOD
const value = try safe.slice(data, offset, length);
const item = try safe.get(T, data, index);
```

### Use Checked Arithmetic for External Values

```zig
// BAD — can underflow silently
const values_size = total_size - header_size;

// GOOD
if (total_size < header_size) return error.InvalidSize;
const values_size = total_size - header_size;

// GOOD
const total = std.math.add(usize, a, b) catch return error.Overflow;
```

### Return Context-Aware Errors

Use specific errors (`error.InvalidBitWidth`, `error.EndOfData`, `error.InvalidPageSize`) instead of generic `error.InvalidData`.

### Validate at API Boundaries

```zig
pub fn writeColumn(values: []const T) !void {
    if (values.len > std.math.maxInt(i32)) return error.TooManyValues;
    // ... proceed with encoding
}
```

### Common Safe Casting Helpers

- `safePageSize(i32) -> error{InvalidPageSize}!usize`
- `safeRowCount(i64) -> error{InvalidRowCount}!usize`
- `extractBitWidth([]const u8, usize) -> error{InvalidBitWidth, EndOfData}!u5`
- `safeTypeLength(?i32) -> error{InvalidTypeLength}!usize`
